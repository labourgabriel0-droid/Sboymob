# WAP LLM Hub (frontend)

Лёгкий фронтенд в стиле WAP/XHTML для общения с несколькими LLM.

## Возможности
- чат с одной или несколькими моделями;
- режимы мышления (быстро / сбалансировано / глубоко);
- флаг веб-поиска;
- добавление фотографии;
- самоулучшение ответа;
- split-view/сравнение ответов;
- история с сохранением в `localStorage`;
- AJAX-переходы между разделами через hash-routing.

## Запуск
Откройте `index.html` в браузере или поднимите простой сервер:

```bash
python3 -m http.server 8080
```

После этого перейдите на `http://localhost:8080`.
